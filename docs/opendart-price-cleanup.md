# OpenDART Price Cleanup

## Scope

2026-11-05 KST 기준 잘못 저장된 확정 공모가를 정리한다. 종목 삭제, 해외 공모 제외, 환불일 재해석, 발송 정책 변경은 이번 작업에 포함하지 않는다. KIND 자동 수집 중단은 유지한다.

## Evidence And Policy

- 21:58 KST 수집본 26건 중 24건의 최신 공시 원문을 직접 조회했다. 신영해피투모로우제12호기업인수목적과 제논 원문은 OpenDART가 파일 없음(014)을 반환했다.
- 기존 정규식은 확정가 문구 뒤 최대 40자의 임의 문자열을 건너뛰어 첫 숫자를 선택했다. 다비오는 인수 총액, 아델은 기존 주식 취득가격, 다른 종목은 희망밴드 하단이나 수수료의 조건값을 확정가로 오인했다.
- 새 규칙은 가격과 인접한 명시적 확정 문구를 요구하고 조건부/예정/가정/범위 표현을 거절한다. 정정 이력에서 가격이 충돌하면 임의로 하나를 고르지 않는다.
- `estkRs.slprc`만으로는 확정 여부를 판단하지 않는다. 과거 신고서 fallback은 기타 메타데이터를 보완할 수 있지만 최신 신고서에 없는 확정가를 되살리지 않는다.
- 원문 캐시와 월별 집계 캐시는 모두 v3로 변경한다. v2와 이전 source snapshot은 감사 이력으로 남기되 새 수집에서 사용하지 않는다.
- 확정 근거가 없으면 `offerPrice=null`로 두고, 확보된 희망밴드는 유지한다. 이를 새 확정가나 확정 취소라는 외부 사건으로 해석하지 않는다.

## Verification

- 단위 테스트: 인수 총액, 기존 취득가, 조건부 가격, 희망가 범위, 예정 가격, 0원 및 충돌하는 정정 가격 차단. 유효 확정 문구와 희망밴드 밖의 실제 확정가 유지.
- 수정 전 백업: `/tmp/ipo-offer-audit/before.json`, `db-before.json`. 원문과 재생 결과도 같은 디렉터리에 보관한다. 임시 파일은 영구 백업이 아니며 저장된 source snapshot을 함께 감사 근거로 삼는다.
- 영향 종목의 기존 READY 알림: 0건. 이번 작업에서는 알림을 발송하지 않는다.
- 배포 후 정상 수집 경로로 갱신하고, DB 결과와 공개 화면을 대조한다. 변경 수가 예상과 다르면 새 값을 임의로 보정하지 않고 공시/캐시 출처부터 확인한다.

## Production Result

- 코드 `1ea2d71`, 배포 `EUQvAM4arjjM5g7x1RzWYmibNnBT`가 build 성공 / Ready임을 확인했다.
